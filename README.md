# TelegramLens

텔레그램 공개 채널에서 도는 종목 이야기를 정리해 **Claude 데스크톱과 Codex**가 직접 조회하게 연결하는 로컬 MCP 서버입니다.

- 요즘 채널에서 많이 언급되는 종목, 언급이 갑자기 늘어난 종목
- 특정 종목이 언제 처음 언급됐고 어떻게 퍼졌는지
- 글에 붙은 기사·공시 링크의 내용까지

TelegramLens는 **LeetKit FULL Package**(StockLens + DartLens + TelegramLens)에 들어 있습니다. 구매와 14일 무료 체험은 **[leetkey.kr](https://leetkey.kr)** 에서 합니다. 설치와 업데이트는 LeetKit Manager에서 버튼으로 합니다.

소스 코드는 공개하지 않습니다. 이 저장소에는 소개와 패치노트만 있습니다.

TelegramLens는 투자자문이나 종목 추천 서비스가 아닙니다. 공개 채널의 글을 AI가 분석에 쓰도록 정리할 뿐이고, 판단은 사용자가 합니다.
