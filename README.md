# TelegramLens

**Claude와 Codex가 텔레그램 주식 채널에서 도는 이야기를 직접 찾아 답하게 연결합니다**

주식 이야기는 기사보다 텔레그램 채널에 먼저 돕니다. 하지만 수십 개 방을 다 읽을 수는 없고, AI는 텔레그램을 볼 수 없습니다.

TelegramLens는 **내 텔레그램 계정으로 가입한 채널**의 글을 내 PC에 모아 종목별로 정리하고, AI가 그걸 조회해서 답하게 합니다. **언제 처음 올라왔는지 시각을 붙이고, 원문에 없는 이유는 지어내지 않습니다.**

TelegramLens는 [LeetKit](https://leetkey.kr) FULL Package에 들어 있습니다. 시세와 수급을 보는 StockLens, 공시를 읽는 DartLens와 함께 씁니다.

## 실제로 돌려준 답

> 한올바이오파마 오늘 왜 빠졌어? 언제부터 얘기가 돌았는지도 알려줘

**2026-09-28 텔레그램 채널, 시간순**

| 시각 | 채널에 올라온 내용 |
|---|---|
| 07:20 | 키움증권 리포트 요약: 파트너사 임상에서 피부홍반루푸스(CLE) 개발 중단 |
| 07:53 | IBK투자증권 리포트: 목표주가 하향, 신약 가치 영향은 제한적 |
| 08:01 | 다올투자증권 리포트: 목표주가 하향 |
| 08:46 | 당일 리포트 3건 정리 |
| 15:45 | 장 마감 정리: 한올바이오파마 −6.87%, CLE 개발 중단 |

원문에 적힌 이유는 파트너사 이뮤노반트의 CLE 2상이 1차 평가지표를 넘지 못해 개발을 중단했다는 소식입니다. 사흘 동안 언급이 없다가 장 시작 1시간 40분 전인 07:20에 처음 올라왔고, 9시 전에 4개 채널에서 6건이 돌았습니다.

## 이렇게 물어봅니다

```
요즘 텔레그램에서 제일 많이 도는 종목 알려줘
어제보다 언급이 갑자기 늘어난 종목 있어?
오늘 채널에서 볼 만한 글이랑 링크 추려줘
```

```
에코프로 관련해서 채널에 올라온 글이랑 붙은 기사 내용 정리해줘
'전고체' 얘기 나온 글 찾아줘
```

## 되는 것

- **많이 도는 종목:** 기간 안에 언급이 많은 종목, 평소보다 언급이 갑자기 늘어난 종목을 찾습니다.
- **퍼진 흐름:** 종목마다 처음 언급된 시각과 시간대별로 퍼진 흐름을 보여 줍니다.
- **원문 검색:** 종목 이름이 없는 산업, 테마 글까지 찾고, 글에 붙은 기사와 블로그 내용까지 뒤집니다.
- **링크 내용:** 글에 붙은 링크의 제목과 본문 발췌를 함께 읽습니다. 공시 링크는 DartLens로 원문을 이어서 읽습니다.
- **오늘의 브리핑:** 많이 도는 종목과 읽을거리를 한 번에 추립니다.

도구는 23개입니다.

## 원칙

- **원문에 없는 이유는 지어내지 않습니다.** 근거는 채널 원문과 글에 붙은 링크입니다.
- **시각을 붙입니다.** 언제 처음 올라왔고 언제 퍼졌는지 적습니다.
- **퍼 나른 글과 따로 쓴 글을 가립니다.** 한 글이 여러 방으로 옮겨졌을 뿐인지, 여러 곳에서 각자 말하고 있는지 구분해서 셉니다.
- **종목 이름은 거래소 종목 목록으로 확인합니다.** 2,700여 종목과 맞춰 봐서 비슷한 단어를 종목으로 잘못 잡지 않게 합니다.

## 내 PC에만 저장합니다

글은 내 텔레그램 계정으로 가입한 채널에서만 모으고, 전부 내 PC에만 저장합니다. 서버로 보내지 않습니다. 새로 가입한 채널은 따로 등록하지 않아도 자동으로 모읍니다. PC가 켜져 있는 동안 모읍니다.

## 설치와 가격

- **설치:** LeetKit Manager에서 버튼을 눌러 설치하고 받은 키를 붙여 넣습니다. 명령어를 칠 일은 없습니다.
- **텔레그램 로그인:** 처음 한 번 Manager의 TelegramLens 카드에서 전화번호로 로그인합니다.
- **체험:** 14일 무료 체험으로 Lens 3개를 전부 써 볼 수 있습니다. 카드 등록 없이 이메일만 있으면 됩니다.
- **가격:** 한 번 결제, 월 구독 없음. TelegramLens는 단품으로 팔지 않고 LeetKit FULL Package에 들어 있습니다.

체험 신청과 가격은 **[leetkey.kr](https://leetkey.kr)** 에서 확인하세요.

## 투자 조언이 아닙니다

TelegramLens는 텔레그램 채널의 글을 AI가 분석에 쓰도록 정리하는 데이터 도구입니다. 투자자문이나 투자일임, 종목 추천 서비스가 아니며, 특정 종목의 매수나 매도를 권유하지 않고 매매 주문 기능도 없습니다. 채널의 글은 사실이 아닐 수 있고, AI의 답변도 참고 자료입니다. 투자 판단과 그 결과에 대한 책임은 투자자 본인에게 있습니다.
