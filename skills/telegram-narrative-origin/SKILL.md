# 종목 내러티브 기원 추적 (언제·어디서·왜)

빈도 순위(trending)는 "지금 많이 언급된다"만 말한다. 이 스킬은 한 단계 깊이 — **그 종목이
언제 처음 터졌고, 어느 채널이 먼저였고, 어떻게 번졌나**를 본다. 선반영/소문/신규 내러티브를
가르는 판단의 핵심이다.

## 언제 쓰나
- "이 종목 왜 갑자기 떠?" / "언제부터 회자됐어?"
- "누가(어느 채널이) 먼저 말한 거야?"
- "<종목> 텔레그램 분위기 / 무슨 말 도는지"
- "이거 선반영이야, 이제 소문 도는 단계야?"
- trending·momentum에서 한 종목을 찍어 "얘 좀 더 파봐"

## 흐름

1. **종단 전개 1콜** — `telegram_timeline(query=종목, hours=72)`
   - 최초 언급 채널·시각, 시간대별 독립 언급·확산 채널 수·velocity·베이스라인 배율을 받는다.
   - "언제 시작 / 어디서 시작 / 가속 구간이 어디"를 여기서 읽는다.
2. **요약·원문 1콜** — `telegram_stock_buzz(query=종목, hours=72, samples=8)`
   - summary(independent·channels·sentiment)와 실제 원문 샘플·`telegram_link`를 받는다.
   - **'왜'의 근거는 전부 여기 samples에서만** 가져온다(아래 절대 원칙).
3. **연관 거시/테마 (선택)** — 종목코드에 안 붙는 배경(정책·산업 이슈)이 의심되면
   `telegram_search("<테마 키워드>", hours=72)` 로 원문 글까지 확인.
4. **종합** — 아래 출력 형식으로 "기원 → 확산 → 근거" 한 흐름 정리.

→ 보통 **2콜(timeline + stock_buzz)**, 배경 필요 시 +1콜.

## 출력 형식

1. **한 줄 결론** — "○월 ○일 ○시경 <채널>에서 처음 거론 → 지금 N개 채널로 확산(평소 대비 ×N배)"
2. **전개 타임라인** — 최초 언급 → 가속 구간 → 현재. 시각·채널 수·velocity를 짧게.
3. **원문 근거 2~3개** — samples에서 인용("…") + 채널명 + `telegram_link`. *이게 '왜'의 전부.*
4. **판단 한 줄** — 아래 가이드로 선반영/소문/신규 중 무엇인지.

## 해석 가이드
- 🟢 **신규 내러티브 후보**: 최근에야 최초 언급 + 짧은 시간에 여러 채널 확산 + baseline 배율 큼.
- 🟡 **소문 단계**: 1~2개 채널(특히 gossip tier)에 집중, 확산 채널 수가 안 늘어남.
- 🔵 **선반영/오래된 이야기**: 며칠 전부터 꾸준, baseline 배율 1 부근 → 이미 알려진 재료.
- 확산 채널이 analyst/research tier로 번지면 신뢰도↑(단순 gossip 확산과 구분).

## 시세·수급을 얹고 싶으면
"그래서 주가는?"이 따라오면 `telegram-buzz-snapshot` 스킬로 넘겨 `get_multi_stocks` /
`get_flow_batch` 배치로 시세·수급을 붙인다(종목당 개별 호출 금지). 기원(텔레)과 반응(시세)을
나란히 두면 선반영 판단이 또렷해진다.

## 🚨 절대 원칙 — '왜'는 원문에서만 (추측 금지)
timeline의 수치는 '언제·얼마나 번졌나'일 뿐 '왜'가 아니다. 종목이 *왜* 떴는지는 **반드시
stock_buzz / timeline 의 samples 원문**에 적힌 내용만 근거로 쓴다. 뉴스 기억·배경지식으로
이유를 지어내지 말 것. 원문에 근거가 없으면 "원문상 이유 불명 — 확산만 관측됨"이라 답한다.
samples에 `telegram_link`가 있으면 사용자가 직접 열어볼 수 있게 함께 제시한다.

## 엣지 케이스
- 종목을 사전에서 못 찾으면("⚠️ … 찾지 못했습니다") 종목명 철자/별칭을 사용자에게 확인.
- timeline이 비면(언급 거의 없음) "추적할 만한 버즈 자체가 없다"고 그대로 알린다(지어내지 말 것).
- 거시·테마(예: "금리", "미국 이란")는 종목코드가 안 붙으니 timeline 말고 `telegram_search`로.
