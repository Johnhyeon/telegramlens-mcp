# 새로 뜨는 종목 (신규 내러티브 포착)

trending(빈도 상위)은 "이미 다들 아는 종목"을 준다. 이 스킬은 정반대 — **평소엔 조용하다
방금 늘어난 종목**을 잡는다. 정보 우위의 본질은 '많이'가 아니라 '먼저'다.

## 언제 쓰나
- "새로 뜨는 거 없어?" / "방금 뭐 터졌어?"
- "오늘 갑자기 회자되기 시작한 종목"
- "지금 급증·가속 중인 거"
- "새 테마/신규 모멘텀 잡아줘"

## 흐름

1. **급증 종목 1콜** — `telegram_momentum(hours=6, baseline_hours=72, top=15)`
   - "평소(72h) 대비 최근 6h에 급증"한 종목. `is_new`(평소 거의 없다 등장)면 신규성 강함.
   - 결과 맨 위 `codes` 배열을 그대로 다음 단계에 쓴다(재파싱 X).
2. **가속 확인 (선택)** — 특정 종목의 '지금 가속 중인지' 보려면
   `telegram_velocity(query=종목, window_hours=6, bucket_minutes=30)` — 직전 버킷 대비 증가율·spike.
   - query 생략 시 velocity 상위 종목 자체를 뽑을 수도 있다(momentum과 교차검증).
3. **노이즈 거르기** — 한 메시지에 종목이 8개 이상 나열되는 '오늘의 리포트·상한가 리스트'류는
   실제 논의가 아니라 끼인 것(저신뢰). samples가 이격도·MA·나열형이면 후순위로 둔다.
4. **시세 반응 (선택)** — "그래서 실제로 움직였나"는 `codes`를 `get_multi_stocks(codes)` 배치
   1콜로(종목당 개별 호출 금지). 깊게 가면 `telegram-buzz-snapshot` 스킬로 수급까지.

→ 보통 **1콜(momentum)**, 검증·시세까지 가도 **3콜** 안.

## 출력 형식

급증 강도 순으로 간결한 목록:

| 종목 | 신규성 | 최근 거론 | 한 줄 근거(원문) |
|---|---|---|---|

- **신규성**: `is_new`면 "평소 거의 없다가", 아니면 "최근 부쩍". recent_channels(채널 수)로 확산 폭.
- **한 줄 근거**: samples 원문에서 내러티브 있는 첫 글 인용(나열형·기술지표 글은 피함).
- 시세를 붙였으면 등락률 열을 뒤에 추가해 '버즈↑ + 시세 반응' 정합 여부 표시.

표 아래 **2~3줄**: 진짜 새 이야기로 보이는 것 1~2개를 콕 집어 "왜 신규로 보는지"(확산 폭·
baseline 배율)를 짚는다. 단, '왜 떴는지'(이유)는 원문 근거가 있을 때만.

## 해석 가이드
- 🟢 **신규 후보**: is_new + 여러 채널 동시 확산 + 원문에 구체적 재료(계약·실적·정책) 언급.
- 🟡 **단발 소문**: 한 채널(특히 gossip)에서만 튐, 확산 안 됨 → 더 지켜볼 것.
- 🔴 **나열 노이즈**: stocks_per_msg_avg 높음(리스트에 끼임) → 실제 모멘텀 아님, 제외.
- 한 종목을 더 파려면 `telegram-narrative-origin` 스킬(timeline)로 기원·확산을 종단 추적.

## 🚨 절대 원칙 — '왜'는 원문에서만 (추측 금지)
momentum·velocity 수치는 '얼마나 급증했나'일 뿐 '왜'가 아니다. 급증 이유를 설명할 땐 **반드시
결과에 동봉된 samples 원문**만 근거로 쓰고, 없으면 "급증은 관측되나 원문상 이유 불명"이라
답한다. 배경지식·뉴스 기억으로 이유를 지어내지 말 것. samples의 `telegram_link`를 함께 제시.

## 엣지 케이스
- momentum이 비면(급증 종목 0) "지금은 새로 튀는 종목이 없다"고 그대로 알린다.
- 처음 수집 중 안내가 나오면 잠시 후 재시도(정상 사이클은 안 막힘).
- 거시·테마성 신규 이슈(종목코드 없음)는 momentum이 못 잡으니 `telegram_search`로 보완.
